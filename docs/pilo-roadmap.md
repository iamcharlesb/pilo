# Pilo roadmap

This roadmap describes planned product work, not shipped capabilities or committed dates. See [Features](../FEATURES.md) for current behavior and [Changelog](../CHANGELOG.md) for completed changes.

## Completed in the current catalog update

- [x] Responsive catalog with all bots, Favorites, Recent and search.
- [x] Added-bot ordering, blue status checks and dark Create bot button.
- [x] Sundar Pichai portrait and independent financial-analysis bot profiles.
- [x] Independence and financial-analysis disclaimer.
- [x] Home navigation and restored run-status regression fixes.

- [x] Named Huddle sessions, participant selection, shared discussion history and read-only multi-bot responses.
- [x] Main-view animation for the selected bot and background-only sidebar animation.

## Next priorities

- [ ] Broaden catalog coverage tests for filtering, onboarding, renamed profiles and keyboard navigation.
- [ ] Expand narrow-pane and accessibility validation across supported desktop sizes.
- [ ] Evaluate stable bot identity mapping across renames and synchronized rosters.
- [ ] Improve financial research deliverables with reproducible model templates and source freshness checks.
- [ ] Document release packaging and upgrade checks as the desktop workflow develops.

These items require implementation and verification before they should be treated as available features. No scheduled bot work or paid job is created by this roadmap.

The separate historical [Fireworks++ framework roadmap](../ROADMAP.md) is not the Pilo application roadmap.
